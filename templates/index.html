Field guide

⌘
SSID
Wi-Fi network name

The name users see when choosing a wireless network.

BSSID
Access point radio MAC address

Identifies a particular wireless access point/radio. One SSID can have multiple BSSIDs.

Signal
Reported signal percentage

A rough indicator from Windows, not a precise distance measurement.

Channel
Radio channel in use

Nearby networks sharing channels may experience congestion or interference.

Security
Authentication / encryption

Shows the security advertised by the access point; it does not prove a network is trustworthy.
